#### YOU NEED CMAKE < 3.5 !

#### WINDOWS ENVIRONMENT VARIABLES TO SET

1. **`COMMONLIB_SSE_FOLDER`**: The path to your clone of Commonlib.
2. **`VCPKG_ROOT`**: The path to your clone of [vcpkg](https://github.com/microsoft/vcpkg).
3. (optional) **`SKYRIM_FOLDER`**: path of your Skyrim Special Edition folder.
4. (optional) **`SKYRIM_MODS_FOLDER`**: path of the folder where your mods are.

#### Mod Page

[Universal Arrow Spin - Nexus](https://www.nexusmods.com/skyrimspecialedition/mods/171136)

Universal Arrow Spin makes arrows spin naturally in flight for improved realism and immersion.
Works at the engine level via SKSE, making it fully compatible with vanilla, DLC, and mod-added arrows - no mesh swapping, no conflicts.
